Phase 1: Simulator notes

Goal
Read a workload file and compare FCFS with round robin using quantums 1, 2, 4, and 8.

Input format
Each process line has: name, arrival time, burst length.
Lines beginning with # are comments.

Information to track for each process
- Name: identifies the process.
- Arrival time: when it becomes ready.
- Burst length: total CPU time it needs.
- Remaining time: CPU time it still needs after running.
- First start time: when it first gets the CPU.
- Completion time: when it finishes.

Scheduling rules
- FCFS: the earliest-arriving ready process runs until it finishes.
- If no process is ready, the CPU waits until the next arrival.
- Round robin: use a time quantum of 1, 2, 4, or 8.
- At a quantum boundary, handle new arrivals before putting the 
  unfinished process at the back of the ready queue.
- If arrival times tie, the smaller process name goes first.

Metrics
- Completion (C) = when the process finished.
- Turnaround (T) = completion time - arrival time.
- Waiting (W)    = turnaround - burst length.
- Response (R)   = first start time - arrival time.
- Count switches when the CPU moves to a different process.
